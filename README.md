# Portfólio — Giovani Vitor

Portfólio profissional desenvolvido em HTML, CSS e JavaScript, com suporte a português e inglês e compatível com GitHub Pages.

## Recursos

- Layout escuro e responsivo para desktop, tablet e celular
- Alternância entre Português e English
- Foto de perfil integrada aos círculos animados
- Tecnologias com ícones
- Imagem real do dashboard CallMeMaybe no projeto em destaque
- Links para LinkedIn, GitHub, e-mail e WhatsApp
- Currículo em português e résumé em inglês
- Download do currículo correspondente ao idioma selecionado
- Favicon personalizado `GV.`
- Metadados básicos de SEO e compartilhamento
- Animações de entrada
- Contadores automáticos
- Consulta da quantidade de repositórios públicos no GitHub
- Botão "Voltar ao topo" com rolagem suave
- Compatibilidade com GitHub Pages
